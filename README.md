# 🌐 `compound-web` Package

Lightweight, high-performance Micro Web Server & REST API framework for the **Compound Programming Language**.

---

## 💻 Installation (via CPM)

```bash
cpm add github.com/ayushhacksethically-code/compound-web
```

---

## 🇮🇳 Hinglish Usage (`app.hg`)

```hinglish
shamil "web"

web.server_banao(8080)

web.route_suno("/", kaam() toh
    wapas web.jawab_bhejo("<h1>Namaste World from Compound Web!</h1>")
khatam)

web.server_chalao()
```

---

## 🇬🇧 English Usage (`app.eg`)

```english
import "web"

web.create_server(8080)

web.listen_route("/", task() do
    return web.send_response("<h1>Hello World from Compound Web!</h1>")
done)

web.start_server()
```
